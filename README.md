# 문자열 덧셈 계산기 ver 1.0

## 주요 기능

### 1️⃣ 문자열 입력

- [x] `덧셈할 문자열을 입력해 주세요.` 출력
- [x] 사용자 입력 받기

### 2️⃣ 커스텀 구분자 추출

- [x] 커스텀 구분자 추출
- [x] 구분자 목록에 추출된 커스텀 구분자 등록

### 3️⃣ 구분자를 이용하여 문자열에서 숫자 추출

- [x] 기본 구분자(`:`,`,`)와 커스텀 구분자로 문자열 분리
- [ ] 분리된 문자를 숫자로 변환

### 4️⃣ 덧셈

- [ ] 추출된 숫자 덧셈 결과 반환

### 5️⃣ 결과 출력

- [ ] `결과 : `와 합산 결과 출력

## 제한 사항

- 커스텀 구분자에 `숫자`는 포함될 수 없다.
- 아무것도 입력하지 않은 공백일 경우 0을 반환하고 이외에는 모두 예외를 발생한다.
    - 즉, `input="" -> result=0` 이지만 `input=",:,1" -> IllegalArgumentException 발생!`
- 입력되는 숫자는 모두 `양수`이다.
